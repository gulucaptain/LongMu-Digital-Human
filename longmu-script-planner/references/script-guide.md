# 用户写稿指南

用户可给普通文章或分镜表，由skill转换。建议说明主题、观众、必须讲清的要点、允许改写范围、已有图片和关键动作；可选填写目标时长、画幅和语气。时长是目标，当前帧数对齐和逐段留白不能保证严格凑整秒，不用拖慢配音填充。

每段分别写台词、画面、字幕要点。一到两句完整台词配一个主动作；纯讲解可只保留说话与眨眼，交互镜头按用户要求明确物体和动作，不给每句话机械加手势。在5–10秒音频预算内尽量合并短句，减少片段与素材数量。

示例：

- 台词：长时间看屏幕，可以安排短暂休息，让视线离开近处。
- 画面：男士停止打字，转向首帧里已有的左侧窗户，随后保持姿势。
- 字幕：短暂休息，移开视线。

“医生突然拿出瓶子、拧盖、给患者滴药并讲原理”应拆为道具介绍、单步示意和原理讲解。精细操作优先用经确认的素材；缺相应素材时先列缺项，不悄悄删掉用户要求展示的步骤。

中文以每秒4–5字初估，20–25字通常适合约5秒，35–40字需重点检查预算。语速、停顿、数字和术语改变实际时长。按自然停顿拆分，不能拆开否定词与对象、条件与结论、数值与单位。短句可合并以减少碎片和静音累积。预览检查补齐尾部，不能让短句说完后站住几秒填满最低时长；连续讲解不每段独立收尾。按[拼接节奏与首尾帧设计](stitching-and-keyframes.md)选择连续接缝或明确切镜，并区分生成时长与最终编辑目标。

text只写真正说出的内容，不含“医生说：”“停顿两秒”“（温柔）”或H3标签。必要时将数字/缩写写成明确读法，准确显示值留在字幕，但不得改变含义。

先按[参考声音规则](voice-reference.md)检查共用参考音频目录。有MP3时使用选定录音，第一段台词也由该声音克隆生成，开头无需迁就参考录音内容或语气。只有无MP3、首次生成固定声音时，第一段才作为声音参考，宜至少约3秒且语气适合全片；已有参考录音的逐字文字应单独提供，不用第一镜台词代替。

不要让图片中没有的眼镜、瓶子、手套或人物突然出现。操作开始和结束姿势要能看清，一段一个主步骤。同一讲话可续接末帧；换场景可以剪切，不要求办公室自然变成诊室。有匹配素材且结束位置必须受控的单步动作，应选择首尾双帧；尾帧不能保证中间操作正确。当前通过Seedance平台准备成对首/尾图，以实际导出的图片为准；缺图记录待补。

当前支持单人讲解、统一旁白单步示意和人物边讲边做单步动作；分别规划talking_head、simple_action和speaking_action。后者需on_camera；现有图里嘴被裁掉时不能保证可见口型。精细医疗操作、多人不同声音、无配音纯动作和复杂长动作需要额外流程/代码扩展。字幕、数字和图解放后期，不要求模型准确画文字；复杂图解和外部实拍插入尚无通用代码入口。

交互画面请写清物体的外观、来源/起始位置、人物与左右手、握法、移动路径、接触关系和稳定结束状态。同一物体继续出现时，下一镜自动复用上一段实际末帧；生成中不逐镜等待人工尾帧审核，整片检查在全部生成完成后进行。详细规则见[交互动作与自动续接](prompt-rules.md#交互动作与自动续接)。
